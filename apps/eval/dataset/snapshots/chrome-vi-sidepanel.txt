browser.sidePanel

Mô tả

Sử dụng API chrome.sidePanel để lưu trữ nội dung trong bảng điều khiển bên của trình duyệt cùng với nội dung chính của trang web.

Quyền

sidePanel

Để sử dụng Side Panel API, hãy thêm quyền "sidePanel" trong tệp manifest của tiện ích:

manifest.json:

{
"name" : "My side panel extension" ,
...
"permissions" : [
"sidePanel"
]
}

Khái niệm và cách sử dụng

API Bảng điều khiển bên cho phép các tiện ích hiển thị giao diện người dùng của riêng chúng trong bảng điều khiển bên, mang lại trải nghiệm nhất quán, bổ sung cho hành trình duyệt web của người dùng.

Giao diện người dùng của bảng điều khiển bên trong trình duyệt Chrome.

Một số tính năng bao gồm:

Bảng điều khiển bên vẫn mở khi bạn di chuyển giữa các thẻ (nếu được thiết lập để làm như vậy).

Tính năng này có thể chỉ hoạt động trên một số trang web cụ thể.

Là một trang tiện ích, bảng điều khiển bên có quyền truy cập vào tất cả API Chrome.

Trong phần cài đặt của Chrome, người dùng có thể chỉ định bên hiển thị bảng điều khiển.

Trường hợp sử dụng

Các phần sau đây minh hoạ một số trường hợp sử dụng phổ biến cho Side Panel API. Hãy xem phần Mẫu tiện ích để biết các ví dụ đầy đủ về tiện ích.

Hiển thị cùng một bảng điều khiển bên trên mọi trang web

Bạn có thể đặt bảng điều khiển bên ban đầu từ thuộc tính "default_path" trong khoá "side_panel" của tệp kê khai để hiển thị cùng một bảng điều khiển bên trên mọi trang web. Đường dẫn này phải trỏ đến một đường dẫn tương đối trong thư mục tiện ích.

manifest.json:

{
"name" : "My side panel extension" ,
...
"side_panel" : {
"default_path" : "sidepanel.html"
}
...
}

sidepanel.html:

<!DOCTYPE html>
<html>
<head>
<title>My Sidepanel</title>
</head>
<body>
<h1>All sites sidepanel extension</h1>
<p>This side panel is enabled on all sites</p>
</body>
</html>

Bật bảng điều khiển bên trên một trang web cụ thể

Tiện ích có thể sử dụng sidepanel.setOptions() để bật bảng điều khiển bên trên một thẻ cụ thể. Ví dụ này sử dụng browser.tabs.onUpdated() để theo dõi mọi nội dung cập nhật được thực hiện cho thẻ. Hàm này kiểm tra xem URL có phải là www.google.com hay không và bật bảng điều khiển bên. Nếu không, hàm này sẽ tắt tính năng đó.

service-worker.js:

const GOOGLE_ORIGIN = 'https://www.google.com' ;

browser . tabs . onUpdated . addListener ( async ( tabId , info , tab ) = > {
if ( ! tab . url ) return ;
const url = new URL ( tab . url );
// Enables the side panel on google.com
if ( url . origin === GOOGLE_ORIGIN ) {
await browser . sidePanel . setOptions ({
tabId ,
path : 'sidepanel.html' ,
enabled : true
});
} else {
// Disables the side panel on all other sites
await browser . sidePanel . setOptions ({
tabId ,
enabled : false
});
}
});

Khi người dùng tạm thời chuyển sang một thẻ không bật bảng điều khiển bên, bảng điều khiển bên sẽ bị ẩn. Bảng điều khiển bên sẽ tự động xuất hiện lại khi người dùng chuyển sang một thẻ mà bảng điều khiển bên đã mở trước đó.

Khi người dùng chuyển đến một trang web không bật bảng điều khiển bên, bảng điều khiển bên sẽ đóng và tiện ích sẽ không xuất hiện trong trình đơn thả xuống của bảng điều khiển bên.

Để xem ví dụ hoàn chỉnh, hãy xem mẫu Bảng điều khiển bên dành riêng cho thẻ .

Mở bảng điều khiển bên bằng cách nhấp vào biểu tượng trên thanh công cụ

Nhà phát triển có thể cho phép người dùng mở bảng điều khiển bên khi họ nhấp vào biểu tượng thanh công cụ hành động bằng sidePanel.setPanelBehavior() . Trước tiên, hãy khai báo khoá "action" trong tệp kê khai:

manifest.json:

{
"name": "My side panel extension",
...
"action": {
"default_title": "Click to open panel"
},
...
}

Bây giờ, hãy thêm mã này vào ví dụ trước:

service-worker.js:

const GOOGLE_ORIGIN = 'https://www.google.com' ;

// Allows users to open the side panel by clicking on the action toolbar icon
browser . sidePanel
. setPanelBehavior ({ openPanelOnActionClick : true })
. catch (( error ) = > console . error ( error ));
...

Mở bảng điều khiển bên theo lập trình khi người dùng tương tác

Chrome 116 ra mắt sidePanel.open() . API này cho phép tiện ích mở bảng điều khiển bên thông qua cử chỉ của người dùng tiện ích, chẳng hạn như nhấp vào biểu tượng hành động . Hoặc hoạt động tương tác của người dùng trên trang tiện ích hoặc tập lệnh nội dung , chẳng hạn như nhấp vào một nút. Để xem bản minh hoạ đầy đủ, hãy xem tiện ích mẫu Mở bảng điều khiển bên .

Mã sau đây cho biết cách mở bảng điều khiển bên chung trên cửa sổ hiện tại khi người dùng nhấp vào trình đơn theo bối cảnh. Khi sử dụng sidePanel.open() , bạn phải chọn bối cảnh để mở. Sử dụng windowId để mở bảng điều khiển bên chung. Ngoài ra, hãy đặt tabId để chỉ mở bảng điều khiển bên trên một thẻ cụ thể.

service-worker.js:

browser . runtime . onInstalled . addListener (() = > {
browser.contextMenus.create({
id : 'openSidePanel' ,
title : 'Open side panel' ,
contexts : [ 'all' ]
} );
} );

browser . contextMenus . onClicked . addListener (( info , tab ) = > {
if (info.menuItemId === 'openSidePanel') {
// This will open the panel in all the pages on the current window.
browser.sidePanel.open({ windowId : tab . windowId } );
}
} );

Chuyển sang một bảng điều khiển khác

Tiện ích có thể sử dụng sidepanel.getOptions() để truy xuất bảng điều khiển bên hiện tại. Ví dụ sau đây đặt một bảng điều khiển bên chào mừng trên runtime.onInstalled() . Sau đó, khi người dùng chuyển đến một thẻ khác, bảng điều khiển bên chính sẽ thay thế bảng điều khiển bên này.

service-worker.js:

const welcomePage = 'sidepanels/welcome-sp.html' ;
const mainPage = 'sidepanels/main-sp.html' ;

browser . runtime . onInstalled . addListener (() = > {
browser . sidePanel . setOptions ({ path : welcomePage });
browser . sidePanel . setPanelBehavior ({ openPanelOnActionClick : true });
});

browser . tabs . onActivated . addListener ( async ({ tabId }) = > {
const { path } = await browser . sidePanel . getOptions ({ tabId });
if ( path === welcomePage ) {
browser . sidePanel . setOptions ({ path : mainPage });
}
});

Trải nghiệm người dùng trên bảng điều khiển bên

Người dùng sẽ thấy bảng điều khiển bên tích hợp sẵn của Chrome trước tiên. Mỗi bảng điều khiển bên sẽ hiển thị biểu tượng của tiện ích trong trình đơn bảng điều khiển bên. Nếu không có biểu tượng nào, thì biểu tượng phần giữ chỗ sẽ xuất hiện cùng với chữ cái đầu tiên trong tên của tiện ích.

Mở bảng điều khiển bên

Để cho phép người dùng mở bảng điều khiển bên, hãy sử dụng biểu tượng hành động kết hợp với sidePanel.setPanelBehavior() . Ngoài ra, hãy gọi sidePanel.open() sau khi người dùng tương tác, chẳng hạn như:

Lượt nhấp dẫn đến hành động

Phím tắt

Trình đơn theo bối cảnh

Cử chỉ của người dùng trên trang tiện ích hoặc tập lệnh nội dung.

Ghim bảng điều khiển bên

Biểu tượng ghim trong giao diện người dùng của bảng điều khiển bên.

Thanh công cụ của bảng điều khiển bên sẽ hiển thị biểu tượng ghim khi bảng điều khiển bên đang mở.
Khi nhấp vào biểu tượng này, bạn sẽ ghim biểu tượng hành động của tiện ích. Khi bạn nhấp vào biểu tượng hành động sau khi ghim, thao tác này sẽ thực hiện hành động mặc định cho biểu tượng hành động và chỉ mở bảng điều khiển bên nếu bạn đã định cấu hình rõ ràng.
